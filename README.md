# Matcha loader

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/adorablewhale/matcha-loader/main/loader.lua"))()
```

Routes by game/place ID and fetches the current individual release. FischHub is
public; TiltLine is offered only to Roblox user 4654017802 and its owner installation.
Terms acceptance is required before loading. Cloud dashboards and named launch
reporting are separate optional choices. No Windows helper is required.
Auto-execute switches remain in INSUI's gear tab. Unsupported games run nothing.
The public build uses renamed locals and encoded blocks; readable gameplay source
remains in private repositories. Download the optional readable-source Windows
helper from https://adorablewhale.world/dashboard when a script needs Windows features.
