# matcha loader

**one line, every script. it picks the right one for the game you're in.**

</div>

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/adorablewhale/matcha-loader/main/loader.lua"))()
```

### what it does

- **auto-picks the script** for your game — fisch gets [fischhub](https://github.com/adorablewhale/fischhub)
- **always the newest release**, nothing to re-download
- **works with autoexec** — choose what runs where in the insui gear tab
- **does nothing in unsupported games**
